Como atualizar o painel todo mês (outubro em diante)

  1. Produtos: na planilha, aba LANCAMENTO_MENSAL, já existe uma linha para cada produto em Out, Nov e Dez. Digite Vendido (venda faturada do mês), Produzido (lotes que entraram) e Estoque do último dia do mês. A coluna Previsão só precisa ser preenchida se o gráfico do sistema mudou.
  2. Clientes: na aba COMPRAS_CLIENTES, cole o relatório de venda por cliente do mês: Mês (10, 11, 12), Código do cliente, Referência e Quantidade. Produto novo para um cliente entra sozinho.
  3. Pronto: salve a planilha (Excel no navegador, OneDrive). O mês de corte avança sozinho. Aqui no painel, clique em Carregar planilha e escolha o arquivo: tudo é recalculado na hora, sem instalar nada.

Dica: o mês só entra nas assertividades quando o Vendido daquele mês estiver preenchido. Use números sem ponto de milhar (2679, não 2.679).

Publicar para todos

Depois de aplicar, publique para que quem tem o link veja os dados novos. Os FCAs editados neste navegador também vão junto.

Chave de publicação do GitHub
  1. Abra github.com/settings/personal-access-tokens/new (logado na conta do painel).
  2. Token name: Painel Gestor DBS · Expiration: 1 ano.
  3. Repository access: Only select repositories → painel_gestor_dbs.
  4. Permissions › Repository permissions › Contents: Read and write.
  5. Generate token, copie o código (começa com github_pat_) e cole abaixo.
